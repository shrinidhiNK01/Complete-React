# Weather App

This is a complete, production-ready, fully functional **Weather App** built as part of the React Mastery Course.

## 🚀 Features
- Complete component architecture
- Advanced state management (Zustand/Context)
- Complete routing and page structure
- Mock API Integration
- Fully styled with beautiful CSS
- Unit & integration tests included

## 📂 Folder Structure
```
Weather App/
├── package.json
├── README.md
└── src/
    ├── index.js
    ├── App.js
    ├── components/
    ├── context/
    ├── hooks/
    └── styles/
```

## 🛠️ Setup & Execution
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
