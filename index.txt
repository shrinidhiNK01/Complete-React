React is a JS library developed to synchronize state management of js and UI DOM. In Old JS we had to manually update the DOM when the state changed, but in React we don't have to do that, it will automatically update the DOM when the state changes.
React is a declarative external library.

components in react :- function and class

props :- 
====================

hooks:-
